Aplicacion creada para alumnos de educacion superior (UPIIG IPN), creada para resolver los problemas relacionados a la logistica y organizacion de los horarios de cada alumno,
organice y aplique lo necesario para proporcionar a los estudiantes lo necesario para solventar sus problematicas de cada semestre, como acomodar su horario separando cada bloque
de cada carrera y cada materia que se debe cursar.
